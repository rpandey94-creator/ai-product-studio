# Engineering roadmap

## Starting sequence

1. **AI Evaluation Workbench — locally runnable real system.** Python package, typed fixtures, four deterministic evaluators, seven passing tests, JSON/CSV/JUnit evidence, browser review interface, architecture, run guide, and learning exercise.
2. **MCP Agent Tool Hub — next.** Actual MCP server/client, tool schemas, scoped permissions, denial paths, audit log, and conformance tests.
3. **Browser-Native AI Vision Lab.** Real ONNX Runtime Web or Transformers.js inference, local image handling, capability detection, accuracy fixtures, and privacy explanation.
4. **RAG Research Assistant.** Licensed corpus, ingestion, hybrid retrieval, citations, abstention, and retrieval/faithfulness evaluation.
5. **Pipecat Voice Agent.** Tested realtime conversation, interruption, latency budget, bounded tool execution, and human handoff.
6. **Controlled AI Developer Agent.** Read-only repository inspection, proposed patches, allowlisted edits, controlled tests, and human review.

This sequence is not a cap. The 64-item catalog stays expandable.

## Definition of implemented

- Actual framework code executed.
- Positive, negative, and edge tests passed.
- Run output and limitations preserved.
- Source, architecture, and zero-card deployment documented.
- Public, browser-side, local, recorded, or simulated status stated explicitly.
- Learning guide includes a feature change and debugging scenario.
- Personal mastery remains separate until demonstrated by the owner.
