# Engineering blueprint index

These blueprints are implementation contracts, not claims that every product exists. Each folder records the product boundary, first executable slice, contracts, quality gates, security posture, economics, and deferred work. The four flagship folders contain an additional architecture decision record.

Status language is strict: **Designed**, **Interactive UX Prototype**, **Locally Implemented and Tested**, and **Public Live Demo**. Technology maturity is tracked separately.
