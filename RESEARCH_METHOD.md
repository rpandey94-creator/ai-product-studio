# Repeatable research method

## 1. Observe demand without confusing signals

Use three evidence levels:

1. **Demonstrated buyer demand** — dated freelance briefs, paid product categories, procurement signals, or credible marketplace reports.
2. **Employer implementation demand** — current Applied AI, AI PM, Solutions, and platform-role descriptions that name concrete systems, constraints, and ownership.
3. **Strategic 2027 opportunity** — an explicit inference from adoption barriers, technology capability, and zero-cost feasibility. It is never presented as proven purchasing demand.

Repository stars are ecosystem evidence only. They do not raise the buyer-demand score by themselves.

## 2. Convert evidence into candidate records

Each candidate requires a unique buyer problem, modality or engineering pattern, user journey, candidate frameworks, architecture, evaluation criteria, relative complexity, and honest implementation state. Near-duplicate chatbots are rejected unless the new record introduces a material domain control, modality, protocol, or infrastructure pattern.

## 3. Prioritize

The current registry weights:

- demand evidence: 30%;
- distinct engineering capability: 30%;
- zero-cost feasibility: 20%;
- inverse implementation cost: 20%.

Scores rank research; they do not claim forecast precision.

## 4. Framework due diligence

For each technology record: use the official repository and documentation; capture point-in-time activity; identify the architectural layer; classify the license precisely; document commercial conditions, dependencies, deployment, alternatives, enabled products, and what this repository actually executes.

Source-available and conditional tools remain explicitly labeled. Model weights, codecs, hosted services, connectors, and extensions may carry terms different from the core repository.

## 5. Promotion gate

A candidate advances from Research Roadmap only when a narrow acceptance test and a zero-card run path exist. It becomes implemented only after real code executes, positive/negative/edge tests pass, reports are preserved, and a learner can reproduce the result.
