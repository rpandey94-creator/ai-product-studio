# Framework and SDK atlas

The browser atlas contains 63 records across agent frameworks, protocols, automation, voice, RAG/search, vision/multimodal, local AI, evaluation/observability, and engineering.

Each record includes:

- actual architectural layer and function;
- official repository and documentation;
- point-in-time repository activity metadata;
- license and source classification;
- commercial-use caution;
- deployment and external dependencies;
- alternatives and products enabled;
- honest implementation status in this repository.

Metadata from all 63 official repositories is preserved in `research/framework-metadata-complete.json`. A push date or star count indicates ecosystem activity only; it is not evidence of buyer demand, quality, security, or legal suitability.

Phoenix is labeled Elastic-2.0, n8n uses its Sustainable Use License, Dify uses a custom license, FFmpeg obligations depend on build configuration, and GitHub Actions is a hosted service governed by service terms. These are not collapsed into “unrestricted open source.”
